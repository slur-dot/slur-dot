### Selected Execution

* **AI Microservices & NLP:** Architected containerized Python environments explicitly routing PyTorch tensors to NVIDIA CUDA GPUs for high-speed Stable Diffusion generation and Low-Rank Adaptation (LoRA) injection. Developed custom RAG (Retrieval-Augmented Generation) pipelines utilizing local, quantized open-source LLMs (`llama.cpp`) to prevent data leakage while maintaining high determinism.
* **Immutable Infrastructure:** Engineered GitOps continuous delivery pipelines utilizing Argo CD and Kubernetes, bridging deployment strategies with localized S3 emulation (MinIO). Replaced traditional server deployments with serverless edge functions and document-level database security.
* **Distributed Logic & State:** Designed enterprise-grade financial state machines using strictly-typed TurboRepo monorepos and distributed Redis message brokering. Built cross-platform mobile ecosystems relying on real-time Socket.io WebSocket connections and resilient MongoDB-backed background job orchestration.
